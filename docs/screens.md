# 画面とURL一覧

既定のポートは 3000（`.env` の `PORT` で変更）。以下は `http://localhost:3000` を起点とした表記です。

## 画面URL

| URL | 画面 | アクセスできる人 |
|---|---|---|
| `/` | `/index.html` へリダイレクト | — |
| `/login.html` | ログイン | 全員 |
| `/index.html` | 分析画面 | FP・管理者 |
| `/admin.html` | 管理画面 | **管理者のみ** |

- 未ログインで `/index.html` を開くと `/login.html?next=/index.html` へ遷移し、ログイン後に元の画面へ戻ります。
- `/admin.html` はサーバ側でも権限を確認しており、FPがURLを直接開くと **403** を返します。画面側のガードだけに頼っていません。
- 書き出したHTMLを `file://` で開いた場合は「単体モード」で起動し、担当先の選択と読み取り機能を隠します。

## 分析画面 `/index.html`

画面上部に**担当先セレクタ**が常時表示されます。

| 操作 | 内容 |
|---|---|
| 担当先の選択 | 自分の担当先を切り替える（未保存の変更があれば確認が入る） |
| ＋ 新規 | 担当先を作成（会社名・業種） |
| 名称・業種の変更 | 既存の担当先を編集 |
| 削除 | 担当先と決算データを削除（確認あり） |
| 💾 保存 | 現在の明細をサーバへ保存 |

右上に利用者名、管理者には「管理画面」リンク、全員に「ログアウト」。

### タブ構成

| タブ | 内容 |
|---|---|
| **① 財務分析** | グラフと指標分析 |
| **② 数値入力** | 決算書の読み込み、明細の編集、集計結果 |
| **③ 読み方フロー** | STEP形式の診断フロー |

### ① 財務分析

**表示切替**

| ボタン | 内容 |
|---|---|
| 全体（BS＋PL） | 資産・負債純資産・費用・収益を並べた比例縮尺チャート |
| PLのみ | 主要項目の推移、原価の内訳、販管費の内訳／1期はウォーターフォール |
| BSのみ | 貸借対照表のみ |
| CS（簡易） | キャッシュフロー（2期以上必要）。8パターン分類と間接法の計算式 |

**期間切替** — 3期比較／1期比較（1期は科目名・数値まで表示する詳細図）

**指標カテゴリ** — 効率性／収益性／安全性／成長性の4つ。各カテゴリに「＋ 詳細指標」で追加表示される指標があります。指標を選ぶと、計算式・意味・期間比較・判定の目安・業種の参考レンジが下部に出ます。

**業種セレクタ** — 参考レンジの比較対象を切り替えます。

### ② 数値入力

| ブロック | 内容 |
|---|---|
| 決算書を読み込む | ファイル選択、補足情報、読み取り実行。結果サマリと警告、元ファイルへのリンク |
| 期タブ | 最大3期。追加・リセット・削除 |
| 単位／従業員数／原価の型 | 10億円〜円（千円を含む）、従業員数（任意）、A製造業／B商業・小売／Cサービス業 |
| 決算書の明細 | **本体**。科目名｜金額｜対応先｜小計｜削除 |
| 貸借バランス | 一致／差額を表示 |
| 確認事項 | 決算書の合計と明細の食い違い、内訳の超過など |
| 集計結果 | 分析に使われる内部項目の値と、その元になった科目 |

明細はセクションごとにグループ化されます。

    資産の部 ／ 負債の部 ／ 純資産の部 ／ 損益計算書 ／ 製造原価 ／ 販管費 ／ その他

各セクションに「＋ 行を追加」があります。対応先が未設定の行は色を変えて表示されます。

**ボタン** — 分析する／この期をリセット／この期を削除／💾 この内容でHTML保存

### ③ 読み方フロー

STEP 1 収益性 → STEP 2 効率性 → STEP 3 安全性 → STEP 4 成長性。各STEPで「まず見る指標」の判定に応じて分岐が強調され、原因を分解する指標をクリックすると解説が出ます。STEP 1 の下に「現金化（利益は現金になっているか）」、STEP 4 の下に「成長の質」が入ります。

## 管理画面 `/admin.html`

| タブ | 内容 |
|---|---|
| **FP管理** | アカウントの追加・編集・停止・削除、パスワード再設定、担当先数と利用回数 |
| **担当先** | 全FPの担当先一覧、担当FPの付け替え |
| **業種平均** | 業種×指標の参考レンジ。空欄にするとその指標では非表示 |
| **判定基準** | 良好／要確認／危険の境界値と比較条件（以上・超・以下・未満）、表示名 |
| **指標の表示** | 指標ごとの表示ON/OFF、標準／詳細の区分、並び順、表示名 |
| **科目マッピング** | 未対応科目の紐付け、科目名→分析項目の対応表 |
| **読み取り履歴** | 元ファイルのダウンロード、抽出した全項目・警告の閲覧 |
| **業種マスタ** | 業種の追加・改名・有効無効・削除 |
| **利用状況** | ログイン・保存・読み取りなどの記録（新しい順200件） |

判定基準・指標の表示・業種平均を変更すると、分析画面の色・バッジ・「判定の目安」表がすべて連動します。
