# 運用ガイド

## セットアップ

```bash
npm install
cp .env.example .env      # 必要に応じて編集（無くても動きます）
npm start                 # http://localhost:3000
```

初回起動時に管理者アカウントが1件だけ作られ、その情報がコンソールに表示されます。

```
[seed] 初期管理者を作成: admin@example.com / admin1234
財務分析システム: http://localhost:3000
DB: /path/to/server/db.sqlite
決算書の読み取り: 無料エンジン(ローカル処理・費用0)
```

> **最初のログイン後、管理画面からパスワードを変更してください。**

## 環境変数

`.env`（`--env-file-if-exists` で読み込むため、ファイルが無くても起動します）

| 変数 | 既定 | 内容 |
|---|---|---|
| `PORT` | `3000` | 待ち受けポート |
| `DB_PATH` | `./server/db.sqlite` | データベースの場所 |
| `COOKIE_SECURE` | — | HTTPS配信時に `1` にするとCookieに `Secure` が付きます |
| `ADMIN_EMAIL` | `admin@example.com` | **初回起動時のみ**使われる初期管理者 |
| `ADMIN_PASSWORD` | `admin1234` | 同上。作成後の変更は管理画面から |
| `OCR_ENGINE` | `free` | `free`（無料・ローカル）／ `claude`（有料） |
| `OCR_KEEP_FILE` | 保存する | `0` にすると送信元ファイルを保存しません |
| `ANTHROPIC_API_KEY` | — | 有料エンジン用。`ANTHROPIC_AUTH_TOKEN` や `ant auth login` のプロファイルでも可 |
| `OCR_MODEL` | `claude-sonnet-5` | 有料エンジンのモデル |
| `OCR_EFFORT` | `medium` | 有料エンジンの effort（`low`〜`high`） |
| `USD_JPY` | `150` | 概算コスト表示の為替レート |
| `TESSERACT_LANG` | `jpn` | Tesseractの言語 |
| `TESSERACT_LANG_PATH` | — | オフライン環境で言語データを同梱する場合のパス |
| `TESSERACT_CACHE_PATH` | — | 言語データのキャッシュ先 |

## バックアップ

データはすべて `server/db.sqlite` にあります。停止中にこのファイルをコピーすれば完全なバックアップです。
稼働中にコピーする場合は `-wal` `-shm` も一緒に取得してください。

読み取り履歴に元ファイルを保存しているため、運用が長くなるとDBが大きくなります。
容量が気になる場合は `OCR_KEEP_FILE=0` を検討してください。

## 権限

| | 分析画面 | 管理画面 | 参照できる担当先 |
|---|---|---|---|
| FP | ○ | × | 自分の担当先のみ |
| 管理者 | ○ | ○ | 全件 |

- `/admin.html` はサーバ側でも権限を確認しており、FPがURLを直接開くと403になります
- FPが他人の担当先にアクセスすると404を返します（存在を伏せるため）
- 有効な管理者が1人だけの場合、そのアカウントの降格・停止・削除はできません（締め出し防止）
- FPを停止またはパスワード変更すると、そのユーザーのセッションは即座に破棄されます

## 注意点

- **FPを削除すると担当先と決算データも削除されます。**削除前に確認が入ります
- 期は1担当先あたり最大3期です
- `exceljs` が依存する `uuid` にmoderateの脆弱性勧告があります（v3/v5/v6で `buf` 引数を渡した際の境界チェック漏れ）。
  本システムは `buf` を渡す経路を持たないため影響を受けません。破壊的アップグレードを避けて据え置いています

## HTMLの書き出し

`② 数値入力` の「💾 この内容でHTML保存」で、入力データを埋め込んだ自己完結型HTMLを書き出せます。
書き出したHTMLを単体で開くと「単体モード」で起動し、担当先の選択と読み取り機能を隠した閲覧専用になります。
サーバが無くても分析結果を確認できるため、顧客への提出用に使えます。

## トラブルシューティング

| 症状 | 確認すること |
|---|---|
| 起動しない | Node.js 24以上か（`node -v`）。`node:sqlite` を使うため必須です |
| ログインできない | 初期管理者はコンソールに表示されます。DBを消すと再作成されます |
| 管理画面が403 | そのアカウントの権限が「FP」です。管理者アカウントでログインしてください |
| 読み取りで503 | `OCR_ENGINE=claude` なのに認証情報が未設定です。`free` に戻すか `ANTHROPIC_API_KEY` を設定 |
| 読み取りで422 | 決算書として解釈できませんでした。ページを絞るか、Excel/CSVでお試しください |
| 科目が分析に入らない | 対応先が未設定です。明細で選ぶか、管理画面「科目マッピング」で紐付けてください |
| 日本語OCRが動かない | 初回はネットワークで言語データを取得します。オフラインなら `TESSERACT_LANG_PATH` を設定 |
| 起動確認したい | `curl http://localhost:3000/api/health`（認証不要） |

## データを初期化する

```bash
rm server/db.sqlite*
npm start
```

すべてのアカウント・担当先・決算データ・マスタの変更が消え、初期状態から作り直されます。
