# 決算書 財務分析システム

FPが担当先企業の決算書を取り込み、収益性・効率性・安全性・成長性を分析するシステムです。

- 決算書の科目を**まとめずに1行ずつ**保持し、マッピング表を通して分析項目へ集計します
- 業種平均や判定基準は**管理画面から変更**でき、全FPの分析画面に即座に反映されます
- 決算書の読み取りは**無料エンジンが既定**（ローカル処理・API費用ゼロ）

## 起動

```bash
npm install
npm start          # http://localhost:3000
```

Node.js 24以上が必要です（同梱の `node:sqlite` を使うため、ネイティブビルドは不要）。
初回起動時に管理者アカウントが1件だけ作られ、その情報がコンソールに表示されます
（既定は `admin@example.com` / `admin1234`）。**最初のログイン後にパスワードを変更してください。**

## データの持ち方

決算書に印字されている科目をまとめずに保持し、分析時にだけ集計します。

```
statement_lines（決算書のまま）              集計          分析
  受取手形        800   → recv  ┐
  売掛金        1,300   → recv  ├─→ 売上債権 2,300 →  流動比率・回転期間 …
  電子記録債権     200   → recv  ┘
  ソフトウェア仮勘定  50   → (未対応)  ← 金額は残るが分析には入らない
```

「決算書の表記」「内部キー」「内部の表示名」は別物として持ちます。対応表は管理画面で編集でき、
未対応の科目を紐付けると次回の読み取りから自動で反映されます。
詳細は [データモデル](docs/data-model.md) を参照してください。

## 構成

```
financial_analysis_system/
├ server/
│  ├ app.js              Express 本体・静的配信・権限ガード
│  ├ db.js               スキーマ定義とマスタの初期投入（node:sqlite）
│  ├ auth.js             Cookieセッション・権限チェック
│  ├ fields.js           内部項目の定義（内部キーと表示名。決算書の科目名とは別物）
│  ├ aggregate.js        明細行 → 内部項目への集計
│  ├ ocr-core.js         有料エンジンのスキーマとプロンプト
│  ├ ocr/
│  │  ├ index.js         エンジンの振り分け（free / claude）
│  │  ├ extract.js       ファイル → 行構造（PDFテキスト層・Tesseract・Excel・CSV）
│  │  ├ dictionary.js    科目名の対応表（account_map の初期投入元）
│  │  ├ parse.js         行構造 → 明細行
│  │  ├ free.js          無料エンジン
│  │  └ claude.js        有料エンジン
│  └ routes/
│     ├ auth.js          ログイン・ログアウト・パスワード変更
│     ├ fps.js           FPアカウント管理・利用状況ログ
│     ├ clients.js       担当先企業と決算データ
│     ├ masters.js       業種・業種平均・判定基準・指標設定・科目マッピング
│     └ ocr.js           決算書の読み取りと履歴
├ scripts/
│  └ compare-ocr.js      有料エンジンの設定別コスト・精度比較
├ public/
│  ├ login.html          ログイン
│  ├ index.html          分析画面
│  └ admin.html          管理画面
└ docs/                  ドキュメント
```

データベースは `server/db.sqlite` に作られます（Gitには含めません）。
